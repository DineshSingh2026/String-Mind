# Knowledge library (raw data)

Drop research results and datasets here. Contents are gitignored except this README.

- `_inbox/`: drop anything here if you're unsure where it goes; it will be sorted.
- One folder per domain (same slugs as the platform: `programming`, `finance`, `healthcare`, ...).
- `_cross-domain/`: reasoning, safety, multilingual, judge-calibration and tooling sources.

Accepted: the research JSON/report, CSV/JSON/JSONL/Parquet datasets, PDFs (syllabi, blueprints), ZIPs, link lists.
Every source is checked for licence and contamination before it is used for questions or the Hive model.
